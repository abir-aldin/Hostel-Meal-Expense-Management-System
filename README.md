# Hostel Meal & Expense Management System

A software solution developed to automate hostel meal calculations and monthly expense settlements.

## Overview

Managing monthly hostel meal accounts manually can be time-consuming and error-prone. This project was developed to simplify the process by calculating meal rates, individual expenses, and payment settlements automatically.

The project was initially developed as a Java-based application using Object-Oriented Programming concepts and later extended into a web-based version with an improved user interface.

## Features

- Manage hostel member information
- Record monthly payments and meal counts
- Calculate meal rate automatically
- Track extra expenses (Rice, Egg, etc.)
- Calculate individual meal costs
- Identify who needs to pay and who will receive money
- Store and manage meal records

## Versions

## Version 1: Java Application

- Developed using Java and OOP concepts
- Console-based application

- Handles meal calculation and payment settlement

## Version 2: Web Application

- Built using HTML, CSS, and JavaScript
- Provides a user-friendly interface
